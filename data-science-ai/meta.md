# About Data Science & AI

CodeVA's *Data Science & AI* course is a full high school elective course to help teachers facilitate a high school elective AI/machine learning ourse aligned with the most recent developments in the machine learning/AI industry. The course provides:

* Practical, hands-on Python coding experiences
* Answer keys, assignments, code examples, and projects for teachers to assign their students
* Annotated Jupyter notebooks, code examples, and project exemplars
* Unplugged activities illustrating fundamental machine learning concepts
* Rigorous mathematical inquiry into how machine learning models make predictions

The course is broken up into four units, covering the basics of data science, the math behind ML predictions, the different types of ML algorithms and thier use cases, and culminating in a student-led data science project on a topic of interest.
