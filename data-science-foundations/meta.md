# About Data Science Foundations

CodeVA's *Data Science Foundations* course is a full semester-long set of lesson plans to help teachers facilitate a high school elective data science course aligned with the Virginia Data Science Standards of Learning. The course provides:

* Practical, hands-on Python coding experiences with optional unplugged scaffolding lessons
* Answer keys, assignments, code examples, and projects for teachers to assign their students
* Annotated Jupyter notebooks, code examples, and project exemplars

The course is broken up into four units, covering the basics of data analysis, visualization, statistial analysis and reasoning, culminating in a student-led data science project on a topic of interest.
